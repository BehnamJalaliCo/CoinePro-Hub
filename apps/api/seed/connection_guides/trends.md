# وصل کردن Google Trends

**چه میدهد:** روند جست‌وجوی کلیدواژه‌های مهم شرکت در گوگل.

## وضعیت امروز
- خواندن خودکار این اتصال هنوز ساخته نشده است.
- گوگل برای Trends راه رسمی و رایگانی برای خواندن خودکار نمیدهد.
- تا آن روز، تحلیلگر عملکرد روند را از صفحه‌ی عمومی Trends میخواند و منبعش را مینویسد.

## اگر میخواهید آماده باشد
1. در اپ، در صفحه‌ی اتصال‌های شرکت، کلیدواژه‌های مهم را بنویسید، هر کدام در یک خط.
2. منطقه را بنویسید، مثلاً ایران.
3. چیزی در خانه‌ی «رمز» لازم نیست.
