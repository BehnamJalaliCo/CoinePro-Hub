# وصل کردن X

**چه میدهد:** تعداد دنبال‌کننده و بازدید پست‌های حساب X شرکت.

## وضعیت امروز
- خواندن خودکار این اتصال هنوز ساخته نشده است.
- خواندن عددها از X رایگان نیست، پس هاب فعلاً آن را نمیخواند.
- عددهای عمومی حساب را تحلیلگر عملکرد از صفحه‌ی عمومی حساب میخواند و منبعش را مینویسد.

## اگر میخواهید آماده باشد
1. در اپ، در صفحه‌ی اتصال‌های شرکت، نام حساب X را بنویسید. نام با علامت @ شروع میشود.
2. فعلاً چیزی در خانه‌ی «رمز» لازم نیست.

**یادآوری:** هر وقت راه رایگانی پیدا شد، همین اتصال بی کار تازه‌ای از شما روشن میشود.
