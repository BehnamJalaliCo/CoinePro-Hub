# contracts/ — قراردادهای API (مال Claude سشن مشورت)

- **قرارداد قبل از صفحه:** هیچ صفحه‌ی وب یا اندروید و هیچ endpoint بدون قرارداد ساخته نمیشود (نقشه‌ی راه، Gate 0).
- **این پوشه را فقط Claude سشن مشورت تغییر میدهد.** Claude سرور اگر خطا یا کمبودی دید، نزدیک‌ترین رفتار امن را پیاده میکند و در گزارش زیر «Contract notes» پیشنهاد میدهد.
- **پیاده‌سازی:** FastAPI در `apps/api/` (مال Claude سرور). OpenAPI 3.1 از خود FastAPI ساخته میشود و در `apps/api/openapi/hq-api.v1.json` commit میشود؛ CI اگر فایل با کد نخواند رد میکند. کلاینت وب (Orval) و اندروید از همان فایل ساخته میشوند.
- **نسخه‌گذاری:** `/api/v1`. تغییر ناسازگار فقط با نسخه‌ی جدید و تأیید مالک.
