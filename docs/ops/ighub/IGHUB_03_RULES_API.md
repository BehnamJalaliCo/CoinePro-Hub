## چرا
مالک، ۲۰۲۶-۱۱-۱۳ (جلسه‌ی F-0018):
- ریلز اول پروچارت منتشر شد (`https://www.instagram.com/reel/Dfq-Zc4lNve/`، id ‏`17866260483693371`). استوری‌اش هم منتشر شد (id ‏`18127217014697683`).
- مالک میخواهد کامنت هوشمند «بازپخش» روی همان پست و جواب دایرکت برای کسی که به استوری «بازپخش» میگوید، **از داخل اپ و برای همه‌ی شرکت‌ها** تنظیم شود.
- موتور قاعده‌ی IG-Hub همه‌ی این‌ها را دارد: `trigger` با مقدار `comment`، `story_reply` یا `dm`؛ `post_ids`؛ `buttons`؛ `public_replies`. ولی فقط پنل (`/api/rules` با نشست مدیر) قاعده میسازد.
- کلید هاب (`/api/v1`، توکن `ighk_`) فقط هنگام انتشار میتواند `comment_rule` بفرستد. راهی برای قاعده‌ی پستی که قبلاً منتشر شده یا قاعده‌ی استوری ندارد.

## کار
1. **`POST /api/v1/rules`** با کلید (`client`، همان `_account` و `_allowed`).
   - **بدنه:**
     ```json
     {"account": "<handle یا id>", "trigger": "comment"|"story_reply"|"dm",
      "keywords": [..], "match": "contains"|"exact"|"starts", "reply_text": "..",
      "buttons": [{"title": "..", "url": "https://.."}], "public_replies": [..],
      "post_ids": ["<Instagram media id>"], "name": "..", "key": ".."}
     ```
   - **ساخت:** با همان اعتبارسنجی `RuleIn` (`problem()`)، به نام `owner_id` کلید. `post_mode` اگر `post_ids` داشته باشد `specific` است، و گرنه `all`. `private_reply` و `enabled` هر دو `true` هستند.
   - **یک قاعده برای هر `key`:** ستون یا جدول کوچک کلید تکراری. بار دوم همان قاعده برمیگردد.
   - **جواب:** `{"id", "trigger", "post_ids", "enabled"}`.
   - **Audit:** `rules.created` با نام کلید.
2. **`hq_publish.py`:** حالت `meta.rule`، بی فایل و بی کپشن، با همان بدنه‌ی بالا.
   - `POST /api/v1/rules` را صدا میزند.
   - یک خط چاپ میکند: `{"external_id": "rule:<id>", "url": null}`.
   - رد شدن یک خط فارسی است و کد ۱.
   - راهنمای بالای فایل همین را بگوید.
3. **تست:** در `backend/tests`، ساخت با کلید، کلید تکراری، حساب بیرون از دسترس کلید (404)، قاعده‌ی نادرست (422)، و `post_ids` غیرعددی.
4. **سند:** `docs/API_PUBLISH.md` بخش «قاعده».
5. **deploy روی همین سرور**، طبق روال خودتان.
   - **سنجش:** `hq_publish.py accounts` هنوز کار کند.
   - **یک قاعده‌ی آزمایشی:** برای ریلز بالا با `trigger: comment`، `keywords: ["بازپخش", "باز پخش"]`، جواب کوتاه و دکمه‌ی لینک. فقط اگر مالک گفت روشن بماند، روشن بماند.
