> ریپوهای `TradeYar`، `CoineProFx` و `CoinePro-App` برای هاب **فقط‌خواندنی‌اند** (`CLAUDE.md`، قانون ۲). هر تغییری که آن‌جا لازم است
> این‌جا فقط **نوشته** میشود. اجرا فقط با اجازه‌ی صریح مالک و طبق `CLAUDE.md` همان ریپو است. هیچ CR خودش اجرا نمیشود.

## قالب هر CR
1. **شناسه، ریپو، وضعیت** (نوشته شد / تأیید مالک / اجرا شد / رد شد).
2. **چرا:** کدام بند پرامپت یا قرارداد هاب به آن نیاز دارد.
3. **چه تغییری:** دقیق و کوچک؛ هر چیزی که لازم نیست، نیست.
4. **قرارداد:** شکل داده، مسیر، امضا. داده‌ی اضافه نمیرود.
5. **امنیت و حریم:** رمزها کجا هستند، چه چیزی هرگز فرستاده نمیشود.
6. **تست قبولی:** چطور مالک و هاب میبینند که درست است.
7. **برگشت:** چطور خاموش میشود.
