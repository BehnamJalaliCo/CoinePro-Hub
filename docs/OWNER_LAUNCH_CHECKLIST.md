# کارهای مالک برای راه‌اندازی، از اول تا آخر

> Claude سشن مشورت، ۲۰۲۶-۱۰-۲۳. پرامپت‌های ۴ تا ۱۴ همه روی سرور هستند. کلید توقف هلدینگ هنوز روشن است و هیچ ایجنتی توکن مصرف نمیکند.
>
> **دستورهای سرور** همیشه در ترمینال خودت و داخل پوشه‌ی پروژه زده میشوند:
> ```
> cd ~/CoinePro-Hub
> ```
> هیچ رمزی را جایی جز همان ترمینال یا اپ نچسبان.

## وضعیت (۲۰۲۶-۱۰-۲۳)
- ✅ ورود به اپ با passkey
- ✅ Codex CLI (ChatGPT)
- ✅ توکن هتزنر
- ⛔ **Gemini CLI منتفی است:** گوگل آن را برای حساب شخصی بسته. Gemini از راه وب وصل میشود.
- ⏳ **ورود وب سه بازیکن:** منتظر اصلاحیه‌ی هاب (`PROMPT_14_1_FIXES.md`).

## بخش ۱: ورود (امروز، ضروری)

### ۱. نصب اپ اندروید
1. فایل `coinepro-hq.apk` را روی گوشی باز کن.
2. اگر اندروید پرسید، «نصب از منابع ناشناس» را برای همان برنامه (مرورگر یا فایل‌منیجر) اجازه بده.
3. نصب را بزن.

- این نسخه با کلید امضای خودت امضا شده و فقط همین نسخه میتواند با passkey وارد شود.
- نسخه‌ی تازه هر بار در GitHub ← Releases ← `android-latest` است.

### ۲. ثبت اولین passkey
**اگر قبلاً در وب یا اپ وارد شده‌ای، این قدم را رد کن.**
1. روی سرور بزن:
   ```
   make owner-enroll
   ```
2. یک لینک یک‌بارمصرف چاپ میشود که ۱۵ دقیقه اعتبار دارد. آن را روی گوشی باز کن.
3. اسم دستگاه را بنویس (مثلاً «گوشی من»). اثر انگشت یا قفل صفحه را تأیید کن.
4. اپ را باز کن ← «ورود» ← اثر انگشت.

### ۳. passkey دوم روی کامپیوتر (بسیار توصیه‌شده)
1. روی کامپیوتر برو به `https://hq.coinepro.com`.
2. وارد شو. پنجره‌ی ورود به تو اجازه میدهد با گوشی تأیید کنی.
3. برو به **تنظیمات ← دستگاه‌ها** و «افزودن passkey» را بزن.

اگر گوشی گم شود، کامپیوتر راه ورودت است. اگر همه‌ی دستگاه‌ها گم شدند، باز همان `make owner-enroll`.

## بخش ۲: آماده‌سازی پیش از روشن کردن شرکت (همه از اپ)

### ۴. بودجه‌ی ماهانه‌ی توکن هر شرکت
- **کجا:** تنظیمات ← کارت استخدام ← بودجه‌ی ماهانه‌ی شرکت‌ها (در خزانه‌ی توکن هم هست).
- **چه کنی:** برای هر شرکت فعال (FX، TY، PC) یک سقف ماهانه بگذار و با اثر انگشت مُهر کن.
- **چرا:** بدون آن، مدیرعامل‌ها نمیتوانند خودشان استخدام کنند.
- **پیشنهاد:** کم شروع کن و بعد از هفته‌ی اول، با دیدن مصرف واقعی بالا ببر.

### ۵. اساسنامه‌ی هلدینگ
- **کجا:** حاکمیت ← اساسنامه.
- **چه کنی:** پیش‌نویس Claude را بخوان، هر جا خواستی اصلاح کن و مُهر کن.
- تا مُهر نشود، فقط چهار خط قرمز پایه اجرا میشود.

### ۶. ماتریس اختیار (یک نگاه کافی است)
- **کجا:** حاکمیت ← ماتریس اختیار.
- **پیش‌فرض‌ها:**
  - روزی حداکثر ۵ استخدام
  - ساعتی ۵ پیام فوری
  - روزی ۳ استوری
  - جمعه‌ها deploy ممنوع
- اگر موافقی، دست نزن.

### ۷. هدف شاخص‌ها (KPI)
- **کجا:** حاکمیت ← کارت‌ها و امتیاز.
- **چه کنی:** برای هر شرکت هدف بگذار؛ مثلاً کاربر فعال یا ثبت‌نام ماهانه.

### ۸. تنظیماتی که پیش‌فرض خوب دارند (اختیاری)
اگر کاری نکنی، همین پیش‌فرض‌ها اجرا میشوند:
- **ناظر کل:** روزی ۳ اجرای مدل، هر کدام ۶۰ هزار توکن؛ حالت نگهبان بعد از ۶ ساعت دوری.
- **مشاور کل:** یادداشت خودکار روی کارت‌ها، روزی حداکثر ۳ یادداشت و ۳ نکته‌ی پیشگیرانه.
- **مدیر کل دیجیتال:** پیش‌بینی‌اش تا بعد از تصمیم تو پنهان میماند.
- **سقف روزانه‌ی کل ایجنت‌ها:** ۶۰۰ هزار توکن.
- **تقویم:** تعطیلات قمری را یک بار با تقویم رسمی چک کن (حاکمیت ← تقویم تغییرات).

## بخش ۳: وصل کردن GPT، Gemini و DeepSeek (ترمینال سرور)

### ۹. ورود CLIها (فقط Codex؛ Gemini CLI منتفی است)
1. ChatGPT:
   ```
   make chatgpt-login
   ```
   یک کد نشان میدهد. روی گوشی، صفحه‌ای را که میگوید باز کن، کد را وارد کن و با حساب ChatGPT خودت تأیید کن.
2. Gemini:
   ```
   make gemini-login
   ```
   یک لینک میدهد. بازش کن، با حساب گوگل خودت وارد شو و کدی را که گوگل میدهد در ترمینال بچسبان.

همین دو کار را از اپ هم میشود کرد: تنظیمات ← اتصال‌ها.

### ۱۰. ورود نسخه‌ی وب (برای عکس، ویدیو و DeepSeek)
این کار با **کامپیوتر** راحت است.
1. در ترمینال کامپیوتر خودت یک تونل باز کن. `<IP-سرور>` را با آدرس سرور هاب عوض کن:
   ```
   ssh -L 6080:127.0.0.1:6080 Hub@<IP-سرور>
   ```
2. در همان پنجره، روی سرور بزن:
   ```
   cd ~/CoinePro-Hub
   make chatgpt-web-login
   ```
3. در مرورگر کامپیوتر برو به `http://127.0.0.1:6080`. یک مرورگر روی سرور میبینی. وارد ChatGPT شو. ۱۵ دقیقه وقت داری.
4. همین را برای بقیه تکرار کن:
   ```
   make gemini-web-login
   make deepseek-web-login
   ```

### ۱۱. روشن کردن بازیکن‌ها
1. روی سرور فایل تنظیمات را باز کن:
   ```
   nano infra/compose/.env
   ```
2. این دو خط را بنویس (یا مقدارشان را `on` کن)، بعد ذخیره کن (`Ctrl+O`، `Enter`، `Ctrl+X`):
   ```
   HQ_SUBSTITUTES=on
   HQ_SUBSTITUTES_WEB=on
   ```
3. بزن:
   ```
   make up
   make install-systemd
   ```

**حافظه‌ی سرور:**
- این دو با هم جا میشوند.
- صدا (TTS)، رسانه، MCP و OCR هر کدام فقط **تنها** کنار سرویس‌ها جا میشوند، نه همه با هم. بخش ۶ را ببین.

## بخش ۴: راه‌اندازی شرکت (لحظه‌ی اصلی)

### ۱۲. خاموش کردن کلید توقف هلدینگ
- **کجا:** اپ ← کنترل ← کلید توقف هلدینگ ← «آزاد کردن» ← اثر انگشت.
- **از این لحظه:**
  - ایجنت‌ها بیدار میشوند و توکن مصرف میکنند.
  - ناظر، مشاور، دستیار و بایگان شروع به کار میکنند.
- **برای توقف دوباره:** همان دکمه. روشن کردن کلید توقف اثر انگشت نمیخواهد، تا سریع باشد.

### ۱۳. باز کردن استخدام
- **کجا:** اپ ← تنظیمات ← استخدام ← «شروع استخدام» ← اثر انگشت.
- **دو حالت:**
  - **واگذار** (تصمیم قبلی خودت): هر مدیرعامل داخل بودجه‌ی ماهانه‌ی شرکتش خودش استخدام میکند. تو با استوری و گزارش باخبر میشوی و هر استخدامی را میتوانی برگردانی. این حالت بودجه‌ی قدم ۴ را لازم دارد.
  - **پیشنهاد:** هر استخدام یک کارت در کارتابل تو میشود و خودت تأیید میکنی.
- **پیشنهاد من:** هفته‌ی اول «پیشنهاد»، بعد «واگذار».
- تیم‌های رسانه هم با همین استخدام ساخته میشوند.

### ۱۴. گزارش صبحگاهی با متن روان (اختیاری)
- **پیش‌فرض:** گزارش صبح بدون مدل و قاعده‌محور است (رایگان).
- **برای متن روان فارسی:** در `infra/compose/.env` بنویس `HQ_MORNING_REPORT_LLM=on`، بعد `make up`. کمی توکن مصرف میکند.

## بخش ۵: بعد از راه‌اندازی، هر وقت خواستی

### ۱۵. پشتیبانی مشتری
1. **جواب‌های آماده:** پشتیبانی ← دانش.
   - مقاله‌های پایه را بنویس و تأیید کن: حداقل موجودی VIP، کد و لینک رفرال، لینک‌های رسمی، قوانین VIP.
   - قالب‌های `safety` و `holding_reply` هر شرکت را مُهر کن.
2. **امتحان پیش از شروع:** خروجی چت‌های قدیمی پشتیبانی را بارگذاری کن (تلگرام دسکتاپ: Export ← JSON) تا ربات روی سؤال‌های واقعی گذشته امتحان شود.
3. **ربات تلگرام:**
   - در BotFather یک ربات بساز.
   - روی سرور بزن: `make telegram-bot-token COMPANY=TY CHANNEL=telegram_bot`
   - بعد از قبول شدن امتحان، کارت «شروع پشتیبانی» را مُهر کن.
4. **پشتیبانی تلگرام بیزینس:** Telegram Premium بخر، Business ← Chatbots را به ربات هلدینگ وصل کن و کارتش را مُهر کن.
5. **Chatwoot** (صندوق پیام پشتیبانی): تصمیمش با توست؛ ساخته شده ولی روشن نیست.

### ۱۶. درآمد (رادار رفرال)
کلید LBank در تریدیار میماند و هاب به آن دست نمیزند. یکی از دو راه:
- **راه الف:** در پنل افیلیت LBank، IP سرور هاب را هم به whitelist اضافه کن. بعد روی سرور `make account-secret KEY=<نام>` بزن و کلید را خودت بده.
- **راه ب:** تریدیار عددها را برای هاب بفرستد. این کار تغییری در تریدیار لازم دارد که جدا انجام میشود.

### ۱۷. رسانه و انتشار
1. **حساب‌های انتشار هر شرکت:**
   - در اپ: سرویس `telegram-<شرکت>` (کانال و ربات ادمین با حق پست و حذف) و `instagram-<شرکت>`.
   - روی سرور:
     ```
     make account-secret KEY=telegram-<شرکت>
     make account-secret KEY=instagram-<شرکت>
     ```
2. **اولین برنامه‌ی انتشار هر شرکت:** رسانه و حقوقی ← برنامه‌های انتشار. مُهرش کن. هر پست اول یک کارت برای تأیید توست.
3. **روشن کردن ساخت ویدیو:** `make media-on` (به بخش ۶، حافظه، نگاه کن).

### ۱۸. صدای هاب
1. **روشن کردن:** `make tts-on`
2. **صدای پیش‌فرض:** `fa_IR-amir-medium` (رایگان). از صفحه‌ی «صدای هاب» گوش کن و نگه دار یا عوض کن.
3. **صدای خودت (اختیاری):** در اپ ۱ تا ۳ دقیقه صدای تمیز ضبط کن. ParsVoice-XTTS فقط برای استفاده‌ی غیرتجاری مجاز است و حافظه‌ی بیشتری میخواهد.

### ۱۹. مشاور حقوقی
- **صندوق ایمیل حقوقی:**
  - در اپ: سرویس `mail` (آدرس، پورت ۴۶۵ و ۹۹۳).
  - روی سرور: `make account-secret KEY=mail` و رمز برنامه (App Password) را بده.

### ۲۰. بایگانی
1. **اولین سندها:** بایگانی ← «سند تازه». فایل‌ها را بده، مشخصات را کامل کن و سندهای نهایی را مُهر کن.
2. **سطح‌ها و مدت نگهداری:** بایگانی ← طرح بایگانی. پیش‌فرض‌ها را یک نگاه بکن.
3. **خواندن خودکار اسکن‌ها (OCR):** `make ocr-fetch` یک بار، بعد `make ocr-on` (حافظه، بخش ۶).

### ۲۱. مدل‌های ارزان با API (MiMo، DeepSeek Flash)
- **کجا:** تنظیمات ← اتصال‌ها ← «افزودن اتصال تازه».
- **چه کنی:** کلید API را خودت در اپ یا با `make connection-secret` بده.

### ۲۲. ساخت سرور برای شرکت تازه
وقتی لازم شد:
1. `make owner-ssh-key` (کلید عمومی خودت)
2. آدرس‌های SSH خودت در تنظیمات
3. بعد روشن کردن ساخت

### ۲۳. ریپو دوباره خصوصی
GitHub ← Settings ← General ← Danger Zone ← Change visibility ← Private (تصمیم قبلی خودت).
