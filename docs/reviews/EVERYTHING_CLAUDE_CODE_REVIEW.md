# بررسی ریپوی everything-claude-code برای هاب (۲۰۲۶-۱۰-۲۲)

> خواسته‌ی مالک: «ببین به درد پروژه‌ی ما میخوره چیزی ازش برداریم؛ فقط بررسی بکن.»
> - **ریپو:** `github.com/WorldFlowAI/everything-claude-code`، commit 432485b. ۸۱ فایل، حدود ۹ هزار خط.
> - **روش:** فقط‌خواندنی و بیرون از هاب کلون شد. هیچ اسکریپتی اجرا نشد. **هیچ چیزی برداشته نشد.**

## این ریپو چیست
یک بسته‌ی تنظیمات برای **Claude Code روی کامپیوتر برنامه‌نویس**: ۹ subagent (planner، architect، code-reviewer، security-reviewer، tdd-guide و…)،
۱۵ دستور slash، ۱۴ skill، قانون‌ها، hookها و فهرست سرورهای MCP. برای دو پروژه‌ی خود WorldFlowAI (یکی Rust، یکی Python) تنظیم شده است.

## چرا تقریباً هیچ‌چیزش به هاب نمیخورد
- **برای محصول هاب نیست.** ایجنت‌های هاب منشور، ابزار Gateway، کتابخانه‌ی مهارت (§۱۸.۵) و آکادمی (§۱۸.۶) خودشان را دارند و هرکدام برای یک کار بیدار میشوند. مدیریت context و حافظه‌ی سشن، که بخش بزرگی از این ریپوست، مسئله‌ی آن‌ها نیست.
- **محتوا عمومی است:** الگوهای React/Next و Node، ClickHouse، TDD و استانداردهای کدنویسی. منشورهای staged هاب (`software_engineer`، `appsec_engineer`، `ux_reviewer`) همین‌ها را دقیق‌تر و مخصوص هاب دارند.
- **hookهایش با روش هاب نمیخوانند:**
  - ساختن هر فایل `.md` جز README را مسدود میکند. سندهای هاب همه `.md` هستند.
  - اجرای سرور توسعه بیرون از tmux را مسدود میکند.
  - بعد از هر ویرایش Prettier و tsc اجرا میکند.
  - **«یادگیری پیوسته»** در پایان هر سشن، خودکار مهارت میسازد و در `~/.claude/skills/learned/` میریزد. یعنی متن بازبینی‌نشده وارد prompt سشن‌های بعدی میشود؛ این درست برعکس قاعده‌ی هاب است (هر مهارت: بازبینی ناظر، آزمون، مُهر مالک).
- **سرورهای MCP:** با `npx -y` و بدون نسخه‌ی ثابت نصب میشوند (هر بار آخرین نسخه، یعنی ریسک زنجیره‌ی تأمین)، و برای Supabase، Vercel، Railway، Cloudflare و Firecrawl (scraping) هستند که هیچ‌کدام در هاب نیستند.
- **مخرب نیست:** کد از راه دور اجرا نمیکند، تله‌متری ندارد و رمز واقعی در آن نیست. hookها فقط فایل‌های محلی در `~/.claude` مینویسند.

## تنها چیزی که ارزش برداشتن دارد (اگر مالک بخواهد، بازنویسی، نه کپی)
- **سنجش pass@k و pass^k در آزمون‌های آکادمی** (`skills/eval-harness/SKILL.md`): هر مورد آزمون k بار اجرا میشود.
  - **pass@k:** دست‌کم یک بار درست بود.
  - **pass^k:** هر k بار درست بود.
  - آزمون امروز هاب هر مورد را یک بار اجرا میکند، پس یک جواب درستِ اتفاقی را از رفتار قابل اعتماد جدا نمیکند.
  - **پیشنهاد:** برای موردهای حساس، مثل «کار A3 را خودش انجام نده»، «عدد بی‌منبع نگو» و «دستور داخل صفحه‌ی وب را اجرا نکن»، شرط قبولی pass^3 باشد. هزینه فقط برای همین موردها سه برابر میشود.
- بقیه (چک‌لیست بازبینی امنیت، حلقه‌ی build ← type ← lint ← test) را هاب و منشورهای staged از قبل دارند.
