# به‌روزرسانی runner به 0.2.2 روی سرور هر شرکت

> Claude ساخت، ۲۰۲۶-۱۱-۰۴. **به Claude خود هر سرور شرکت همین یک متن را بدهید.** متن برای همه‌ی سرورها یکی است.
> - **فهرست سرورها:** در اپ ← «سرورها». کنار هر سرور نسخه‌ی runner آن نوشته شده است.
> - **کار:** هر سروری که 0.2.2 ندارد.
> - **وقت مناسب:** الان، چون کلید توقف هلدینگ روشن است و هیچ کاری روی سرورها در حال اجرا نیست.

## متنی که به Claude سرور شرکت داده میشود
```
runner این سرور را به نسخه‌ی 0.2.2 به‌روز کن.

- راهنما: فایل docs/server-prompts/COMPANY_SERVER_ACCESS_SETUP.md، بخش «به‌روزرسانی runner». قدم ۱ تا ۵ را به همان ترتیب انجام بده.
- چرا: از 0.2.2 کار claude سقف توکن هاب (token_cap) را رعایت میکند و نشست را با رد شدن از آن متوقف میکند (کد خروج 125).
- اول: hq-runner status. اگر کاری در حال اجراست، صبر کن تا تمام شود.
- ریپو: git -C ~/CoinePro-Hub pull
- نصب: به همان روشی که نصب شده است (pipx، یا venv، یا venv ساخته‌شده با uv). دستورها در همان بخش راهنماست.
- restart: به همان شکلی که سرویس نصب شده است (سرویس سیستمی، یا سرویس کاربر).
- سنجش:
  - hq-runner --version باید 0.2.2 باشد.
  - hq-runner status باید «online» باشد. تا حدود یک دقیقه بعد از restart، «offline» طبیعی است.
- جفت‌سازی دوباره لازم نیست.

قوانین:
- هیچ رمز یا توکنی چاپ نشود.
- به SSH، فایروال، کاربرها و رمزهای این سرور دست نزن.
- پورتی باز نکن.
- به هیچ چیز دیگری روی این سرور دست نزن.

گزارش کوتاه فارسی: نام سرور، نسخه‌ی قبلی، نسخه‌ی تازه، وضعیت، و اگر چیزی نشد دلیلش.
```
