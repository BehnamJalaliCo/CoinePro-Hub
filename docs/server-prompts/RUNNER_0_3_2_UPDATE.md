# به‌روزرسانی runner به 0.3.2 روی سرور هر شرکت

> Claude سشن مشورت، ۲۰۲۶-۱۱-۰۹. **به Claude خود هر سرور شرکت همین یک متن را بدهید.** متن برای همه‌ی سرورها یکی است.
> - **سرورها:** همه‌ی سرورهای شرکت‌ها که در اپ ← «سرورها» هستند و runner آن‌ها 0.3.2 نیست. کنار هر سرور نسخه‌ی runner آن نوشته شده است.
> - **وقت مناسب:** بعد از اینکه Claude سرور هاب پرامپت ۳۰ را deploy کرد و گزارش سبز داد، و وقتی روی آن سرور کاری در حال اجرا نیست.
> - **چرا:**
>   - **از 0.3.1:** کار Claude Code روی سرور شرکت با اکانت Claude هاب اجرا میشود (شرکت‌ها اشتراک جدا لازم ندارند).
>   - **از 0.3.2:** فایل‌هایی که یک نوبت کار در پوشه‌ی `out/` میسازد، با لینک به جلسه برمیگردند (قرارداد §۴۳).
>   - هر سروری که هنوز 0.3.0 است، با همین یک بار به‌روزرسانی هر دو را میگیرد.

## متنی که به Claude سرور شرکت داده میشود
```
runner این سرور را به نسخه‌ی 0.3.2 به‌روز کن.

- راهنما: فایل docs/server-prompts/COMPANY_SERVER_ACCESS_SETUP.md، بخش «به‌روزرسانی runner». قدم‌ها را به همان ترتیب انجام بده.
- اول: hq-runner status. اگر کاری در حال اجراست، صبر کن تا تمام شود.
- ریپو: git -C ~/CoinePro-Hub pull
- نصب: به همان روشی که نصب شده است (pipx، venv، یا venv ساخته‌شده با uv). برای pipx:
  pipx install --force --python python3.12 ~/CoinePro-Hub/services/company-runner
- restart: به همان شکلی که سرویس نصب شده است (سرویس سیستمی hq-runner@<کاربر>، یا سرویس کاربر).
- سنجش:
  - hq-runner --version باید 0.3.2 باشد.
  - hq-runner status باید «online» باشد. تا حدود یک دقیقه بعد از restart، «offline» طبیعی است.
- جفت‌سازی دوباره لازم نیست. لاگین Claude روی این سرور هم لازم نیست.

قوانین:
- هیچ رمز یا توکنی چاپ نشود.
- به SSH، فایروال، کاربرها و رمزهای این سرور دست نزن.
- پورتی باز نکن.
- به هیچ چیز دیگری روی این سرور دست نزن.

گزارش کوتاه فارسی: نام سرور، نسخه‌ی قبلی، نسخه‌ی تازه، وضعیت، و اگر چیزی نشد دلیلش.
```

## سنجش در هاب
- **در اپ:** صفحه‌ی هر سرور نسخه‌ی 0.3.2 را نشان میدهد.
- **از Claude هاب:** میتوانید بپرسید: «نسخه‌ی runner همه‌ی سرورها از `GET /api/v1/infra/servers` چیست؟»
- **کارگاه هلدینگ:** این راهنما برای آن نیست. کارگاه با قدم‌های پرامپت ۳۰ نصب میشود.
