## چرا
آخرین ساخت پنل وب مال ۲۰۲۶-۱۱-۰۱ است. پس صفحه‌های پرامپت ۲۴ و ۲۵ هنوز در وب نیستند: دفتر مدیر کل، جلسه‌ی هر فرمان، بوم شرکت‌ها و پول. نسخه‌ی وب الان 0.15.0 است و با اپ اندروید یکی است.

## کار
1. شاخه‌ی اصلی را `git pull` کن و `server/p25-1-web` را بساز.
2. فقط سرویس `web` (پروفایل `web`) را از `apps/web` بساز و بالا بیاور.
3. `make verify-live`.
4. **سنجش‌ها** (عدد یا بله/خیر):
   - `https://hq.coinepro.com/healthz` جواب ۲۰۰ میدهد.
   - نسخه‌ی پنل 0.15.0 است.
   - صفحه‌ی اصلی (`/`) با ورود مالک باز میشود و `GET /api/v1/office` را صدا میزند. این را از لاگ Caddy یا api بسنج، بی هیچ توکن یا شناسه‌ای.
   - حافظه‌ی آزاد سرور بعد از بالا آمدن.
