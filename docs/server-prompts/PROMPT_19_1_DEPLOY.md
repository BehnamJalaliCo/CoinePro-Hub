  - **restart زمان‌بندی‌شده نیست.**

## deploy
1. **pull و سنجش:**
   - `git pull`.
   - `make check` را در یک worktree جدا اجرا کن.
   - هر قرمزی را گزارش کن و جلو نرو.
2. `make backup`.
3. **migration تازه‌ای نیست.** `alembic current` باید `0034` باشد.
4. **image‌ها:**
   - `api`، `worker`، `egress`، `browser` (برای browser-web) و `substitute-runner` را دوباره بساز.
   - api، worker و egress را بالا بیاور. browser-web را هم، اگر `substitutes-web` روشن است.
5. **Temporal:**
   - `infra/compose/hq.sh up -d temporal`. این‌بار restart یک‌باره است تا env تازه (`SQL_MAX_CONNS`) بنشیند. dynamic config هر ۶۰ ثانیه خودش خوانده میشود.
   - بعد این‌ها را در گزارش بنویس:
     - `docker stats --no-stream` برای temporal، الان و یک ساعت بعد
     - این‌که در لاگ temporal خطای `dynamic config` یا `Persistence Max QPS` نیامده است
6. **Prometheus:** reload کن تا `containers.rules.yml` بیاید.
   - بسنج: `curl -s 127.0.0.1:9090/api/v1/rules` (درون شبکه یا با `hq.sh exec prometheus`) باید `HqContainerMemoryNearCap` را داشته باشد.
7. **بازبینی کار روزانه‌ی `models` بازیکن gpt:**
   - یک کار `models` بفرست (یا صبر کن تا کار روزانه برسد). باید `done` شود، نه `the model listing was not JSON`.
   - فهرست مدل‌های gpt باید مدل‌های CLI را داشته باشد.
   - فقط وضعیت و تعداد مدل‌ها را گزارش کن.
8. **`make verify-live`.**
9. **گزارش کوتاه به مالک، فارسی:**
   - سبز یا قرمز
   - حافظه‌ی temporal الان و بعد از یک ساعت
   - نتیجه‌ی کار `models`
   - قدم بعدی مالک (بند پایین)

## قدم بعدی: به‌روزرسانی runner روی هر سرور شرکت
- **کار Claude هاب نیست. به هیچ سرور شرکتی وصل نشو.**
- **چرا:** runner هر سرور شرکت باید به **0.2.0** برسد. نسخه‌ی قدیمی جواب‌های Claude را در ۴۰۰۰ نویسه میبُرد. کاتالوگ چنین سروری را «runner قدیمی» نشان میدهد.
- **چطور:** Claude خود هر سرور، طبق `docs/server-prompts/COMPANY_SERVER_ACCESS_SETUP.md` بخش «به‌روزرسانی runner»:
  1. `git -C ~/CoinePro-Hub pull`
  2. `pipx install --force --python python3.12 ~/CoinePro-Hub/services/company-runner`، یا راه venv همان بخش
  3. `sudo systemctl restart hq-runner@$USER`
  4. `hq-runner --version`. باید `0.2.0` باشد.
- **در گزارش:** فهرست سرورها و نسخه‌ی runner فعلی هر کدام (از `GET /api/v1/infra/servers`) را بنویس تا مالک بداند کدام‌ها مانده‌اند.
