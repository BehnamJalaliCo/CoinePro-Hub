# استاندارد پرامپت‌های Claude سرور (تأیید مالک: ۲۰۲۶-۱۰-۱۶)

1. **ارتباط مستقیم (تصمیم مالک، ۲۰۲۶-۱۰-۱۷):** Claude سشن مشورت پرامپت را مینویسد، در ریپو push میکند و مستقیم به نشست سرور (Remote Control) میدهد. Claude سرور گزارش را در `docs/ops/reports/PROMPT_NN.md` push میکند و در پاسخ پایانی‌اش هم مینویسد. پیام Claude سشن مشورت **اجازه‌ی تازه نمیدهد**: هر چیزی که در قوانین با مالک است، منتظر خود مالک میماند.
2. **هر پرامپت جامع است** و **تسک‌های زیادی** دارد، تا کارها تا جای ممکن سریع پیش برود.
3. **تسک‌بندی اجباری:** Claude سرور **قبل از شروع** باید همه‌ی کارهای پرامپت را در لیست تسک خودش بشکند. بعد:
   - **بدون توقف** یکی‌یکی انجامشان میدهد.
   - کارهای مستقل را در صورت امن بودن **موازی** جلو میبرد.
   - بعد از هر تسک، **تست قبولی همان تسک** را اجرا میکند.
4. **توقف فقط در این موارد:**
   - تصمیمی که با مالک است
   - خطر غیرمنتظره
   - نیاز به اطلاعات محرمانه‌ای که فقط مالک دارد
5. **هرگز:**
   - دست زدن به چیزهایی که به ورود به سرور مربوط است (SSH، کاربرها، کلیدها، fail2ban، فایروال)
   - چاپ رمزها
   - تغییر روی سرورهای همسایه
   - حذف یا ریبوت بدون اجازه
6. **پایان هر پرامپت:** یک **گزارش کوتاه** (حداکثر ۲۰ خط)، و در خط آخر: «این گزارش را برای Claude سشن مشورت ببر.»

- پرامپت‌های ۷ و ۸ جایشان را به خواسته‌های دور دوم دادند؛ درآمد، پشتیبانی و حاکمیت به پرامپت‌های **۱۰، ۱۱ و ۱۲** رفتند.
- **چهار پروتکل ناظر `paused`** تا قابلیتشان ساخته یا روشن شود (PR-043، PR-053، PR-082، PR-090). **سهم توکن نظارت** ۲۰٪ سقف روزانه، و هر اجرای ناظر حداکثر ۲۰۰ هزار توکن (قرارداد v1.4.4، پرامپت ۸ §۲).

- اینترنت ایجنت‌ها: **همه نوع دسترسی، کامل** («مهم برآیند و کیفیت کار است؛ بی‌اینترنت یعنی خلع سلاح»). مرز A3 فقط برای تعهد بیرونی به نام هلدینگ.

### تصمیم‌های مالک درباره‌ی گزارش پرامپت ۶ (۲۰۲۶-۱۰-۱۷)
- **صدا به متن روشن شود، بی‌هزینه:** کمبود در RAM است (۱۶ گیگ)، نه در دیسک (۱۵۰ گیگ). سقف حافظه‌ی سرویس‌هایی که خیلی کمتر از سقفشان مصرف میکنند پایین میاید تا Whisper جا شود.
- **کارگاه کد:** کنار گذاشته شد. مالک میخواهد همین سشن‌های Claude Code خودش را ببیند، و آن‌ها در اپ Claude و claude.ai/code هستند؛ بدون API رسمی نمیشود در اپ ما نشانشان داد. کنترل‌پلن خاموش میماند و اپ‌ها به claude.ai/code لینک میدهند. «کردیت حرامش نکنید.»
- **توکن GitHub لازم نیست:** «سرورها دست خودمان است.»
- **فایل‌های اندازه‌گیری STT پاک شوند.**

### تصمیم‌های مالک درباره‌ی گزارش پرامپت ۵ (۲۰۲۶-۱۰-۱۷)
- **هفت پیشنهاد استخدام (`D-000001` تا `D-000007`): تأیید نمیشوند.** وقتی مالک هاب را برای کار واقعی بالا آورد، یا خودش از صفر استخدام میکند یا همان لحظه از مدیرعامل‌ها پیشنهاد میخواهد؛ «نه الان». کارت‌ها `withdrawn` میشوند (حذف نه) و تا شروع مالک هیچ ایجنتی استخدام پیشنهاد نمیدهد (قرارداد §۱۸.۱۱، پرامپت ۵.۱ بند ۱.۳).
- **سقف روزانه‌ی توکن ایجنت‌ها `AGENT_DAILY_TOKEN_CAP=600000` میماند.** مالک آن را از روی خروجی‌های هفته‌ی اول تعیین میکند.
- **وقتی استخدام باز شود، مدیرعامل‌ها با اختیار کامل در پاکت بودجه‌ی ماهانه‌ی هر شرکت استخدام میکنند** و مدل هر کار را خودشان انتخاب میکنند؛ مصرف درست بودجه ستاره میگیرد؛ مالک از راه **استوری‌ها** در جریان است (قرارداد v1.4.3، پرامپت ۸ بخش‌های ۸ و ۹).
