# استاندارد پرامپت‌های Claude سرور (تأیید مالک: ۲۰۲۶-۱۰-۱۶)

1. **مالک رابط است.** Claude سشن مشورت پرامپت را مینویسد، مالک به Claude سرور میدهد، و گزارش را برمیگرداند.
2. **هر پرامپت جامع است** و **تسک‌های زیادی** دارد، تا کارها تا جای ممکن سریع پیش برود.
3. **تسک‌بندی اجباری:** Claude سرور **قبل از شروع** باید همه‌ی کارهای پرامپت را در لیست تسک خودش بشکند. بعد:
   - **بدون توقف** یکی‌یکی انجامشان میدهد.
   - کارهای مستقل را در صورت امن بودن **موازی** جلو میبرد.
   - بعد از هر تسک، **تست قبولی همان تسک** را اجرا میکند.
4. **توقف فقط در این موارد:**
   - تصمیمی که با مالک است
   - خطر غیرمنتظره
   - نیاز به اطلاعات محرمانه‌ای که فقط مالک دارد
5. **هرگز:**
   - دست زدن به چیزهایی که به ورود به سرور مربوط است (SSH، کاربرها، کلیدها، fail2ban، فایروال)
   - چاپ رمزها
   - تغییر روی سرورهای همسایه
   - حذف یا ریبوت بدون اجازه
6. **پایان هر پرامپت:** یک **گزارش کوتاه** (حداکثر ۲۰ خط)، و در خط آخر: «این گزارش را برای Claude سشن مشورت ببر.»
