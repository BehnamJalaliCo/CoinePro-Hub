# نصب runner ستاد روی سرور یک شرکت

> - **برای چه کسی:** Claude خود هر سرور شرکت (FX، TY، PC و بعدی‌ها)، نه Claude هاب.
> - **چه وقت:** بعد از اینکه هاب پرامپت ۱۷ را deploy کرد.
> - **تصمیم مالک (۲۰۲۶-۱۰-۳۰):** ایجنت‌های هلدینگ روی سرورهای خود مالک کار میکنند (قرارداد هاب §۲۶).

## کار
1. **کاربر:** همان کاربر کاری این سرور را به کار ببر، کاربری که Claude Code، Docker و git با آن کار میکنند. کاربر تازه نساز.
2. **نصب runner:** از ریپوی هاب (`BehnamJalaliCo/CoinePro-Hub`، پوشه‌ی `services/company-runner/`) طبق README همان پوشه نصب کن، برای همین کاربر.
3. **جفت‌سازی:** دستور زیر را اجرا کن:
   ```
   hq-runner pair --company <CODE> --name <نام سرور> --hub-ip 10.10.1.4
   ```
   - یک کد کوتاه (مثل `ABCD-1234`) نشان میدهد.
   - این کد را به مالک بگو تا در اپ ستاد تأیید کند: صفحه‌ی شرکت ← «سرورها» ← «وصل کردن سرور».
   - **شبکه:** `--hub-ip 10.10.1.4` یعنی ارتباط از شبکه‌ی خصوصی هلدینگ رد میشود. اگر این سرور هنوز عضو شبکه‌ی خصوصی نیست (مثل IG-Hub)، به مالک بگو آن را از کنسول هتزنر به شبکه اضافه کند. تا آن موقع runner از آدرس عمومی کار میکند.
   - **اگر این سرور API انتشار دارد** (مثل IG-Hub برای اینستاگرام): یک دستور محلی انتشار بساز که فایل و متن را بگیرد و از API همین سرور پست یا استوری کند. مسیرش را به مالک بگو تا در سری رسانه ثبت شود.
4. **سرویس دائمی:** بعد از تأیید، systemd unit را فعال کن (`hq-runner run`) و با `hq-runner status` بسنج که «online» است.
5. **گزارش به مالک،** فارسی و کوتاه:
   - نام سرور
   - کاربر
   - نسخه‌ی runner
   - وضعیت

## قوانین
- **رمز:** هیچ رمز یا توکنی چاپ نشود.
- **دست‌نخورده:** به SSH، فایروال، کاربرها و رمزهای این سرور دست نزن. runner به هیچ‌کدام نیاز ندارد.
- **پورت:** پورتی باز نکن. runner فقط از داخل به `hq.coinepro.com` وصل میشود.
