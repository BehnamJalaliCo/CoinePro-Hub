# به‌روزرسانی runner به 0.3.6 روی سرور هر شرکت و IG-Hub

> Claude سشن مشورت، ۲۰۲۶-۱۱-۱۲. **به Claude خود هر سرور همین یک متن را بده.** متن برای همه‌ی سرورها یکی است.
> - **سرورها:** پروچارت، کوینه‌پرو FX، تریدیار و IG-Hub. یعنی هر سروری که در اپ ← «سرورها» هست و runner آن 0.3.6 نیست.
> - **کارگاه هلدینگ:** این راهنما برای آن نیست. Claude سرور هاب آن را در پرامپت ۳۶ ارتقا میدهد.
> - **وقت مناسب:**
>   - بعد از اینکه Claude سرور هاب پرامپت ۳۶ را deploy کرد و گزارش سبز داد.
>   - وقتی روی آن سرور کاری در حال اجرا نیست.
> - **چرا:** رفع‌های امنیتی و پایداری ممیزی ۲۰۲۶-۱۱-۱۱ (قرارداد §۵۶.۸)، سازگار با 0.3.5. عجله‌ای نیست؛ 0.3.5 هم با هاب کار میکند.
>   - سوکت ابزارها و hook فقط درخواستِ همان نوبت را میپذیرند.
>   - پوشه‌ی خصوصی نوبت یا درست آماده میشود یا نوبت اجرا نمیشود. نصب runner و Claude Code پشت دیوار فقط‌خواندنی است.
>   - دانلود ورودی‌ها لینک گذاشته‌شده را دنبال نمیکند.
>   - رویدادها وقتی هاب در دسترس نیست دور ریخته نمیشوند.
> - **وابستگی تازه:** ندارد (`requirements.lock` عوض نشده است).

## متنی که به Claude هر سرور داده میشود
```
runner این سرور را به نسخه‌ی 0.3.6 به‌روز کن.

- راهنما: فایل docs/server-prompts/COMPANY_SERVER_ACCESS_SETUP.md، بخش «به‌روزرسانی runner». قدم‌ها را به همان ترتیب انجام بده.
- اول: hq-runner status. اگر کاری در حال اجراست، صبر کن تا تمام شود.
- ریپو:
  - git -C ~/CoinePro-Hub fetch origin claude/coinepro-hub-setup-hsvnw7
  - روی همین شاخه باش و pull کن. اگر تغییر محلی هست، دست نزن و گزارش کن.
- نصب: به همان روشی که نصب شده است (pipx، venv، یا venv ساخته‌شده با uv). برای pipx:
  pipx install --force --python python3.12 ~/CoinePro-Hub/services/company-runner
- restart: به همان شکلی که سرویس نصب شده است (سرویس سیستمی hq-runner@<کاربر>، یا سرویس کاربر).
- سنجش:
  - hq-runner --version باید 0.3.6 باشد.
  - hq-runner status باید «online» باشد. تا حدود یک دقیقه بعد از restart، «offline» طبیعی است.
  - hq-runner sandbox-check: نتیجه‌اش (on یا off و دلیل) را بنویس. اگر off است، کار نمی‌ایستد؛ فقط گزارش کن.
- جفت‌سازی دوباره لازم نیست. لاگین Claude روی این سرور هم لازم نیست.

قوانین:
- هیچ رمز یا توکنی چاپ نشود.
- به SSH، فایروال، کاربرها و رمزهای این سرور دست نزن.
- پورتی باز نکن.
- به هیچ چیز دیگری روی این سرور دست نزن.

گزارش کوتاه فارسی: نام سرور، نسخه‌ی قبلی، نسخه‌ی تازه، وضعیت، نتیجه‌ی sandbox-check، و اگر چیزی نشد دلیلش.
```
