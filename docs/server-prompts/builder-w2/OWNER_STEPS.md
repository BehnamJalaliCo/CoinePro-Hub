# کارهای یک‌باره‌ی مالک برای خط تولید و رشد

> Claude ساخت، ۲۰۲۶-۱۱-۰۴. به ترتیب، فقط یک بار. همه‌ی کلیدها فقط در OpenBao ذخیره میشوند و دیگر نمایش داده نمیشوند.

## ۱. دادن پرامپت به Claude سرور هاب
- `docs/server-prompts/PROMPT_22_DEPLOY.md`، فقط مرحله‌ی ۱.

## ۲. ورودها در مرورگر هاب (در ترمینال خودتان، هر کدام یک بار)
- **AI Studio برای صدا:** `make aistudio-web-login`، با همان حساب گوگل پرو.
- **پینترست برای الگوها:** `make pinterest-web-login`.
- **ChatGPT:** اگر Claude هاب گفت وارد نیست، `make chatgpt-web-login`.

## ۳. IG-Hub
- فایل `docs/server-prompts/IGHUB_PUBLISH_API.md` را به Claude خود IG-Hub بدهید. این همان درخواست تغییری است که میگوید IG-Hub برای پست زمان‌دار، کاور، کپشن و استوری همان روز چه چیزی باید باز کند.
- بعد در اپ: شرکت ← «اتصال‌ها» ← اینستاگرام ← آدرس API و نام حساب. کلید را با `make growth-secret` بگذارید.

## ۴. کلیدهای دیگر (هر وقت خواستید)
- **یوتیوب:** client id، client secret و refresh token در اتصال یوتیوب.
- **سایت وردپرس:** آدرس سایت و application password.
- **Google Ads و Meta Ads:** فقط اگر تبلیغ دارید. توقف خودکار فقط وقتی کار میکند که کلیدشان گذاشته شده باشد.

## ۵. تصمیم‌های حافظه‌ی سرور (هر کدام جدا)
- **n8n** (اتوماسیون‌های قاعده‌ای): به Claude هاب بگویید «n8n را روشن کن». بعد خودتان `make n8n-secret` را اجرا کنید.
- **خبرنامه (Listmonk):** به Claude هاب بگویید «خبرنامه را روشن کن». ساختن کاربر API، SMTP و آدرس عمومی آن با شماست (`infra/newsletter/README.md`).

## ۶. اولین خط تولید
1. **ساختن خط:** اپ ← شرکت ← «خط تولید» ← «خط تازه» ← قالب «ریلز اینستاگرام».
2. **تنظیم:** گوینده، پوشه‌ی کاور (از «کتابخانه») و پرامپت‌ها را تنظیم کنید.
3. **آزمایش:** «آزمایش کامل» را بزنید. خروجی هر مرحله را میبینید و چیزی منتشر نمیشود.
4. **روشن کردن:** اگر خوب بود، به Claude هاب بگویید «مرحله‌ی ۳ پرامپت ۲۲»، تا `HQ_LINES=on` شود.
5. **حالت خودکار:** خط اول در حالت «پیش‌نویس» است و هر انتشار مُهر شما را میخواهد. بعد از ۷ اجرای خوب، «خودکار کن» ظاهر میشود.

## ۷. شرکت تازه
- با فرمان صوتی یا متنی بگویید «یک شرکت تازه برای … بساز». کارت «شرکت آماده» در گزارش فرمان میآید. کد و نام را بنویسید و مُهر کنید.
