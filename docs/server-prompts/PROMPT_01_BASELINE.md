# پرامپت ۱: آماده‌سازی پایه‌ی سرور CoinePro HQ

> **برای مالک:** کل متن زیر خط را کپی کن و به Claude Code روی سرور هاب بده. وقتی کارش تمام شد، گزارش کوتاهش را برای Claude سشن مشورت بیاور.

---

تو **Claude Code روی سرور هاب «CoinePro HQ»** هستی. CoinePro HQ ستاد مرکزی یک هلدینگ ایجنتیک است. مالک (مدیر کل) کار را مرحله‌به‌مرحله جلو میبرد و رابط بین تو و Claude سشن مشورت است. **این مرحله فقط آماده‌سازی پایه‌ی سیستم است.** هیچ بخشی از خود محصول (API، دیتابیس، n8n، وب و غیره) ساخته نمیشود.

## مشخصات
- **این سرور:** IP خصوصی `10.10.1.4`، شبکه‌ی خصوصی هتزنر (`10.10.1.0/24`). کاربر کاری: `hub`.
- **همسایه‌ها** (همه production): `10.10.1.1` Pro-Chart، `10.10.1.2` CoinePro-FX، `10.10.1.3` TradeYar.

## قوانین
1. **به هیچ چیزی که به ورود به سرور مربوط است دست نزن:** SSH و تنظیماتش، کاربرها و رمزها، `authorized_keys`، fail2ban، ufw و iptables. فایروال با خود مالک است (در کنسول هتزنر).
2. **فقط روی همین سرور کار کن.** به همسایه‌ها **فقط ping** مجاز است.
3. **هیچ رمز، توکن یا کلید خصوصی را چاپ نکن.**
4. **فقط کارهای همین پرامپت را انجام بده.** اگر به چیز غیرمنتظره یا پرریسکی خوردی، **متوقف شو و از مالک بپرس.**
5. **چیزی را حذف نکن، و سرور را ریبوت نکن.** اگر ریبوت لازم شد، فقط در گزارش بگو.
6. **فقط نرم‌افزار رایگان و متن‌باز،** از منبع رسمی هر نرم‌افزار.
7. **خروجی ترمینال انگلیسی، توضیحات فارسی.**

## کارها
**الف) بررسی:**
- سیستم‌عامل، CPU، RAM، دیسک، swap
- منطقه‌ی زمانی و همگام‌سازی ساعت
- IP خصوصی و ping به سه همسایه
- به‌روزرسانی‌های در انتظار
- آیا Docker نصب است؟ نسخه‌ی Claude Code؟
- اگر ریپو کلون شده: مسیر، شاخه، و آدرس remote (بدون هیچ اطلاعات ورود)

**ب) آماده‌سازی سیستم:**
- `apt update` و `apt upgrade`، به‌صورت غیرتعاملی و **بدون ریبوت**
- نصب ابزارهای پایه: `git`، `curl`، `jq`، `htop`، `unzip`، `ca-certificates`
- منطقه‌ی زمانی **UTC**، و همگام‌سازی ساعت فعال
- swap ۸GB اگر وجود ندارد، با `vm.swappiness=10`
- سقف حجم journald: ۱GB
- unattended-upgrades فقط برای به‌روزرسانی‌های امنیتی، با `Automatic-Reboot "false"`

**پ) Docker:**
- **Docker Engine و Compose plugin** از مخزن رسمی Docker برای Ubuntu
- اضافه کردن `hub` به گروه docker (فقط گزارش بده که بعد از ورود مجدد فعال میشود؛ کسی را بیرون نکن)
- فایل `/etc/docker/daemon.json`: محدودیت لاگ (`json-file`، `max-size 10m`، `max-file 3`) و `live-restore: true`
- تست با `docker run --rm hello-world`

## گزارش پایانی
وقتی کارت تمام شد، **یک گزارش کوتاه** (حداکثر ۲۰ خط) با همین قالب بده:

```
PROMPT_01 REPORT
- Server: OS / CPU / RAM / Disk / Swap / TZ
- Done: ...
- Not done / problems: ...
- Reboot needed: yes/no
- Checks: docker --version | docker compose version | hello-world | ping 10.10.1.1-3
- Repo: path / branch / remote (or "not cloned")
```

و **در خط آخر به مالک بگو:** «این گزارش را برای Claude سشن مشورت ببر.»

بعد **متوقف شو.** مرحله‌ی بعد با پرامپت ۲ میاید.
