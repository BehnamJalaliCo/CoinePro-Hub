# پرامپت ۱: بررسی و آماده‌سازی پایه‌ی سرور CoinePro HQ

> **برای مالک:** کل متن زیر خط را کپی کن و به Claude Code روی سرور هاب بده. گزارش آخرش را برای Claude (در سشن مشورت) بیاور.

---

تو **Claude Code روی سرور هاب «CoinePro HQ»** هستی. CoinePro HQ ستاد مرکزی یک هلدینگ ایجنتیک است. مالک (مدیر کل) با مشورت قدم‌به‌قدم کار را جلو میبرد. **این مرحله فقط بررسی و آماده‌سازی پایه‌ی سرور است.** هیچ بخشی از خود محصول (API، دیتابیس، n8n، وب و غیره) ساخته نمیشود.

## مشخصات شبکه
- این سرور: **IP خصوصی `10.10.1.4`** روی شبکه‌ی خصوصی هتزنر `prochart-internal` (`10.10.0.0/16`، subnet `10.10.1.0/24`، zone eu-central).
- همسایه‌ها:
  - `10.10.1.1` Pro-Chart
  - `10.10.1.2` CoinePro-FX
  - `10.10.1.3` TradeYar
- **همه‌ی همسایه‌ها سرور production هستند.**
- کاربر کاری: `hub` (نه root). پورت SSH: **1367**.

## قوانین (در همه‌ی مراحل)
1. **هیچ رمز، توکن یا کلید خصوصی را چاپ نکن.** فقط نام متغیر را بگو. کلید عمومی (`.pub`) چاپ‌شدنی است.
2. **فقط روی همین سرور کار کن.** به سرورهای همسایه **فقط ping** مجاز است. SSH نزن، اسکن پورت نکن، و هیچ تغییری روی آن‌ها نده.
3. **قبل از هر تغییر،** برنامه‌ی دقیق (چه دستوری، چرا، چطور برمیگردد) را بگو و منتظر **«تأیید»** مالک بمان. **فقط بخش الف بدون اجازه مجاز است.**
4. **مالک نباید پشت در بماند.**
   - قبل از خاموش کردن ورود با رمز یا ورود root، باید ورود با کلید برای `hub` در یک **ترمینال جدا** تست شود و مالک تأیید کند.
   - سشن فعلی را تا آخر باز نگه دار.
   - **قبل از restart هر سرویس مربوط به SSH یا فایروال، با `sshd -t` و `ufw show added` بررسی کن.**
5. **هیچ چیزی را حذف نکن** مگر با اجازه.
6. **پورت SSH همان 1367 میماند.**
7. **خروجی ترمینال انگلیسی، توضیحات فارسی.**
8. **فقط نرم‌افزار رایگان و متن‌باز** و از منبع رسمی هر نرم‌افزار.

## الف) بررسی (فقط خواندنی، بدون اجازه)
موارد زیر را بررسی و گزارش کن:
- نسخه‌ی سیستم‌عامل، hostname، تعداد CPU، RAM، دیسک، swap
- کاربرها، عضویت `hub` در گروه sudo
- تنظیمات SSH: `Port`، `PermitRootLogin`، `PasswordAuthentication`، `PubkeyAuthentication`، `KbdInteractiveAuthentication`
- وجود `authorized_keys` برای `hub` و root (فقط وجود داشتن یا نداشتن؛ محتوا را چاپ نکن)
- وضعیت ufw، و پورت‌های باز (`ss -tlnp`)
- اینترفیس شبکه‌ی خصوصی و IP آن، و ping به `10.10.1.1`، `10.10.1.2` و `10.10.1.3`
- منطقه‌ی زمانی و همگام‌سازی ساعت
- به‌روزرسانی‌های در انتظار، و وضعیت unattended-upgrades
- آیا Docker نصب است؟ نسخه‌ی Claude Code؟ آیا fail2ban نصب است؟

بعد از گزارش **توقف کن** و برنامه‌ی بخش‌های ب تا ت را برای تأیید ارائه بده.

## ب) امن‌سازی (بعد از تأیید مالک)
1. **ورود با کلید:**
   - مالک کلید عمومی‌اش را میدهد. آن را در `authorized_keys` کاربر `hub` قرار بده.
   - مالک ورود را در ترمینال جدا تست میکند.
   - **فقط بعد از تأیید مالک:** `PasswordAuthentication no`، `PermitRootLogin no`، `KbdInteractiveAuthentication no`، `MaxAuthTries 3`، و Port همان 1367.
2. **fail2ban** برای sshd روی پورت 1367.
3. **ufw:**
   - پیش‌فرض: ورودی‌ها بسته، خروجی‌ها باز.
   - مجاز: `1367/tcp`، `80/tcp`، `443/tcp`.
   - روی اینترفیس خصوصی فعلاً فقط ICMP. سرویس‌های بعدی در مراحل بعد اضافه میشوند.
   - **اول قانون 1367 اضافه شود، بعد ufw فعال شود.**
4. **سیستم:**
   - unattended-upgrades، فقط برای به‌روزرسانی‌های امنیتی
   - منطقه‌ی زمانی UTC
   - همگام‌سازی ساعت فعال
   - swap ۸GB در صورت نبودن (`vm.swappiness=10`)
   - سقف حجم journald

## پ) Docker (بعد از تأیید مالک)
- **Docker Engine و Compose plugin** از مخزن رسمی Docker برای Ubuntu.
- اضافه کردن `hub` به گروه docker.
- `/etc/docker/daemon.json`: محدودیت لاگ (`json-file`، `max-size 10m`، `max-file 3`) و `live-restore: true`.
- تست با `docker run --rm hello-world`.

## ت) اتصال به GitHub (بعد از تأیید مالک)
1. یک کلید SSH از نوع ed25519 مخصوص این سرور بساز (`~/.ssh/coinepro_hq_deploy`).
2. **فقط کلید عمومی** را نشان بده.
3. مالک آن را به ریپوی `BehnamJalaliCo/CoinePro-Hub` اضافه میکند: Settings ← Deploy keys. دسترسی نوشتن طبق تصمیم مالک.
4. **فقط همین یک ریپو.** به ریپوهای دیگر دسترسی گرفته نمیشود.
5. بعد از تأیید مالک: کلون در `/home/hub/CoinePro-Hub`، و تنظیم `user.name` و `user.email` گیت طبق گفته‌ی مالک.

## ث) گزارش نهایی

```

### Changed (each item: what, why, how to roll back)

- ping 10.10.1.1/2/3 →

- ...
```

**بعد از گزارش متوقف شو.** مرحله‌ی بعد با پرامپت ۲ میاید.
