## ۰. تصمیم‌های مالک (۲۰۲۶-۱۰-۱۷)
1. **صدا به متن روشن شود، بی‌هزینه.** کمبود جا در RAM (۱۶ گیگ) است، نه در دیسک (۱۵۰ گیگ). راه دوم گزارش خودت را اجرا کن: سقف حافظه‌ی سرویس‌هایی که خیلی کمتر از سقفشان مصرف میکنند پایین بیاید.

   - **adapter چهارم: `subscription`.** Claude Code زیر اشتراک هلدینگ اجرا میشود، از همان مسیر و اعتبار claude-runtime. هر سشن در یک کانتینر sandbox یک‌بارمصرف روی خود هاب است و در هر لحظه فقط **یک** سشن اجرا میشود.
   - **محدودیت‌های sandbox:**
     - کاربر غیر root، rootfs فقط‌خواندنی، و فقط پوشه‌ی کار قابل نوشتن است.

   - **اعتبار git هرگز وارد sandbox نمیشود.**
     - هاب repo را clone میکند و کپی‌اش را به sandbox میدهد.
     - push شاخه‌ی `hq/<ref>` (با refspec ثابت) و باز کردن PR را **خود هاب** بعد از approval انجام میدهد، با دسترسی git که مالک قبلاً روی هاب گذاشته است.
     - اگر هاب به ریپوی یک workspace دسترسی ندارد، آن workspace `no_access` نشان داده شود و در گزارش بیاید.
   - **مصرف:** سهمیه‌ی اشتراک با ایجنت‌ها مشترک است و controller سهمیه و سقف روزانه آن را میبینند. مصرف به‌عنوان equivalent cost با task class `workshop` در دفتر خزانه ثبت میشود، و همان سقف دلاری grant اجرا میشود.

   - **adapter `managed`:** ساختش بماند ولی پیش‌فرض نیست.
   - **تست:**
     - یک سشن ساختگی در sandbox، تا ساختن branch و رسیدن approval، پیش میرود.
     - push فقط `hq/<ref>` است و روی همان ref.
     - در محیط sandbox، transcript و رویدادها هیچ اعتباری پیدا نمیشود.
     - سشن دوم در صف میماند.

## ۳. ریز
- **ffmpeg:**
  - در لغو هم kill شود، نه فقط در timeout.
  - `-threads` سقف داشته باشد.
  - fallback فاصله‌ی یکنواخت زمان کل محدود داشته باشد.
- **guard فقط‌افزودنی:** فقط آپلودهای مالک را جابه‌جا کند، نه خروجی‌ها و transcriptهای هلدینگ. ایجنت‌های هلدینگ آپلودِ هنوز پیوست‌نشده‌ی مالک را نبینند.
- **Range:**
  - طول عدد سقف داشته باشد (امروز بیش از ۴۳۰۰ رقم به 500 میرسد).
  - چند-محدوده یا unit ناشناخته نادیده گرفته شود و 200 برگردد.
- **Content-Disposition:** با `filename*=UTF-8''…` بیاید، برای نام فارسی.
- **«stt 503 busy»:** با «خاموش» یکی حساب نشود؛ دوباره تلاش شود.
- **نرمال‌ساز:** «میدانها» به «می‌دانها» نشکند، و «ای» ندا به کلمه‌ی قبل نچسبد.
- **`frames`:** گزارش و کد یکی شوند: `[{id, at_s}]`.
- **ICC:** profile رنگ عکس‌های P3 حفظ شود.
- **رویداد command:** `duration_s` داشته باشد؛ هر دو اپ نشانش میدهند.
- **`/live`:** `?after` را بپذیرد.
- **cursor:** cursor گم‌شده‌ی رویدادهای runtime approval تکراری نسازد.
- **سشن خودکار:** فرمان کدی که مدل مسیرش را یافته، فقط وقتی سشن را خودکار باز کند که یک قاعده هم آن را تأیید کند.
- **شرکتِ رویدادها:** شرکت `workshop.events` در دیتابیس به شرکت سشن بسته شود.
