# کارهای یک‌باره‌ی مالک برای «گفتگو»

> Claude ساخت، ۲۰۲۶-۱۱-۰۴. به ترتیب و فقط یک بار. کلید فقط در OpenBao ذخیره میشود و دیگر نمایش داده نمیشود.

1. **پرامپت هاب:** `docs/server-prompts/PROMPT_23_DEPLOY.md`، مرحله‌ی ۱، را به Claude هاب بدهید. این بعد از پرامپت ۲۲ است.
2. **ساختن کلید:** در Google AI Studio یک کلید API بسازید و صورتحساب پروژه را فعال کنید. پلن پولی را پیشنهاد میکنم، چون داده‌ی آن برای آموزش استفاده نمیشود.
3. **دادن کلید:** اپ ← «گفتگو» ← دکمه‌ی 🔑. کلید را بچسبانید و با اثر انگشت تأیید کنید. چراغ از زرد سبز میشود. اگر قرمز شد، دلیلش زیر چراغ است.
4. **سقف ماه:** همان‌جا یک سقف بگذارید (مثلاً ۱۰ دلار). وقتی پر شود، صدا خودکار ارزان‌تر میشود و قطع نمیشود.
5. **صداها:** برای هر نقش با «بشنوید» صدا را انتخاب کنید. منشی پیش‌فرض صدای خانم دارد، ناظر صدای آقا و دستیار صدای مرد جوان.
6. **Flash-Lite:** یک بار فارسی آن را بشنوید. اگر خوب نبود، آن را از زنجیره بردارید.
7. **صدای محلی رایگان (اختیاری):** به Claude هاب بگویید «مرحله‌ی ۲ پرامپت ۲۳، Piper را روشن کن». حدود ۳۲۰ مگابایت حافظه میگیرد.
8. **شروع:** دکمه‌ی گفتگو را بزنید و حرف بزنید.
   - پیش‌فرض «مشورت» است.
   - برای صورت‌جلسه بگویید «صورت‌جلسه کن» یا «جلسه‌ی کاری».
   - برای آوردن مدیر بگویید «مدیرعامل … را بیاور» یا دکمه‌ی «+» را بزنید.
