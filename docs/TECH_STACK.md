# CoinePro HQ — فهرست فناوری‌ها و کتابخانه‌ها

> **وضعیت:** ❓ **پیشنهاد Claude، در انتظار تأیید مالک** (۲۰۲۶-۱۰-۱۶)
>
> **خواسته‌ی مالک:** از همین ابتدا **بزرگ‌ترین، بهترین و باکیفیت‌ترین کتابخانه‌ها** انتخاب شوند، تا اگر ۶ ماه یا ۵ سال بعد هلدینگ **۴۰ شرکت** شد، **زیرساخت عوض نشود.**
>
> **معیار انتخاب:**
> - استاندارد صنعت و بالغ
> - جامعه‌ی کاربری بزرگ
> - **از یک سرور تا کلاستر بدون بازنویسی بزرگ میشود**
> - هم‌خانواده با ریپوهای فعلی، جایی که منطقی است

## ۱. سمت سرور
| بخش | انتخاب | چرا |
|---|---|---|
| زبان و API | **Python 3.12+ / FastAPI / Pydantic v2** | استاندارد اکوسیستم هوش مصنوعی؛ همان stack TradeYar و FX |
| ORM و migration | **SQLAlchemy 2 (async) / Alembic** | بالغ‌ترین در پایتون |
| دیتابیس | **PostgreSQL 17 + pgvector** | با partitioning، read replica و در صورت نیاز Citus تا مقیاس خیلی بزرگ رشد میکند |
| جداسازی شرکت‌ها | **`company_id` روی همه‌ی داده‌ها + Row-Level Security** در Postgres | ۴۰ شرکت یا بیشتر بدون نشت داده، با اجرا در خود دیتابیس |
| گردش‌کار پایدار | **Temporal** | استاندارد صنعت برای کارهای طولانی، منتظر ماندن چندروزه برای تأیید، retry و زمان‌بندی، در مقیاس خیلی بزرگ. ⚠️ **تغییر ADR-002:** قبلاً «اول Postgres jobs» بود. با خواسته‌ی «زیرساخت عوض نشود»، Temporal از روز اول پیشنهاد میشود. |
| رویدادها و استریم زنده | **NATS JetStream** | سبک روی یک سرور، و کلاستر برای مقیاس بالا؛ مبنای استریم زنده‌ی ایجنت‌ها برای ۴۰ شرکت |
| Cache | **Redis** | استاندارد |
| لایه‌ی ارائه‌دهنده‌های مدل | **LiteLLM** برای همه‌ی APIها (OpenAI، Google، Anthropic API و بیش از ۱۰۰ ارائه‌دهنده) **+ آداپتور اختصاصی اشتراک Claude** (Claude Code / Agent SDK) | بالغ‌ترین لایه‌ی چندارائه‌دهنده، با شمارش توکن و هزینه، بودجه برای هر کلید و تیم، و fallback. پایه‌ی خزانه‌ی توکن و §۱.۱۳ |
| Runtime ایجنت Claude | **Claude Agent SDK** (رسمی) | ابزار رسمی Anthropic؛ شامل MCP، Skills و subagent |
| سیاست و دسترسی | **Open Policy Agent (OPA)** | استاندارد صنعت؛ کلاس‌های A0 تا A4 و پاکت اختیار، به شکل قانون تست‌پذیر |
| اتوماسیون قاعده‌محور | **n8n** (self-hosted) | تصمیم D-16 |
| فایل و صوت | **S3 API** (Hetzner Object Storage) | استاندارد؛ قابل جابه‌جایی به هر S3 دیگر |
| رمزها | **OpenBao** (شاخه‌ی متن‌باز Vault) | استاندارد Vault، بدون قفل لایسنس |
| مشاهده‌پذیری | **OpenTelemetry + Prometheus + Grafana + Loki + Tempo** | همان خانواده‌ی سرورهای فعلی، به‌علاوه‌ی trace کامل هر ایجنت |
| قرارداد API | **OpenAPI 3.1** (ساخته‌شده از FastAPI) | منبع ساخت کلاینت وب و اندروید |
| اجرا | **Docker Compose** برای حالا؛ ایمیج‌ها و پیکربندی **آماده‌ی Kubernetes** | انتقال به چند سرور فقط تغییر پیکربندی است، نه بازنویسی |

|---|---|

## ۵. نکته‌ی صادقانه
- **«بزرگ‌ترین» همیشه به معنای «بهترین برای امروز» نیست.** این فهرست ابزارهایی است که **از یک سرور تا کلاستر بدون بازنویسی** بزرگ میشوند.
- **بیشترِ مقیاس‌پذیری برای ۴۰ شرکت از طراحی داده میاید** (شرکت به‌عنوان داده، و RLS)، نه از خود کتابخانه.
- **Temporal و NATS روی یک سرور هم سبک اجرا میشوند.** روی سرور ۱۶ گیگی جا دارند.
