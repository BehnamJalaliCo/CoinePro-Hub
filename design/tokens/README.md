# design/tokens — توکن‌های «دیوان» (منبع واحد حقیقت)

- **`divan.tokens.json`:** قالب W3C Design Tokens (DTCG)، سازگار با Style Dictionary v4. دو تم: **`night`** و **`day`**. ✅ مرجع رنگ، تایپ، فاصله، شعاع، اندازه، خط، ارتفاع، حرکت و صدا.
- **`CONTRAST.md`:** نسبت کنتراست WCAG هر رنگ متن روی صفحه و کاشی. قاعده: متن ≥ ۴.۵:۱ (≥ ۳:۱ از ۲۴ پیکسل). همه‌ی مقادیر فعلی پاس شده‌اند.

## قواعد
1. **هیچ رنگ، فاصله یا مدت‌زمانی مستقیم در کد وب یا اندروید نوشته نمیشود.** همه از خروجی‌های تولیدشده از همین فایل میایند.
2. **خروجی‌ها** (در فاز ساخت، با Style Dictionary):
   - وب: `apps/web/src/styles/tokens.css` (متغیرهای CSS، با `[data-theme="night"|"day"]`)
   - اندروید: `apps/android/core/designsystem/.../DivanTokens.kt` (رنگ‌ها، تایپ و فاصله‌ی Compose)
   - خروجی‌ها **هرگز دستی ویرایش نمیشوند**؛ CI اگر خروجی با منبع نخواند، رد میکند.
3. **تغییر توکن = تغییر این فایل + تأیید مالک** (Visual Gate).
4. **دو فلز:** `gold.*` فقط برای اقتدار مالک (فرمان، مُهر، تصمیم، اقدام اصلی، مشاور)؛ `silver.*` برای ایجنت‌ها و سیستم.
5. **دو واریانت فونت:** `font.family.text` (ارقام فارسی) برای متن؛ `font.family.figures` (ارقام لاتین، `tnum`) برای ارقام بازار و داده.
6. **محور `dots`:** فقط در نشان‌نوشته (۲) و عنوان‌های تشریفاتی (۱)؛ متن ۰.
