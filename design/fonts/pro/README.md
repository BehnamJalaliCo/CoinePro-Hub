# IRANYekanX Pro (the owner's licence, 2026-11-09)

The full family for the workshop's motion graphics and renders (contract §43): installed for the
`studio` user in `~/.local/share/fonts/IRANYekanX-Pro/`, so Chromium, ffmpeg (drawtext) and any
tool on the workshop find it by family name.

| Folder | Family | What |
|---|---|---|
| `static/` | `IRANYekanX` | 11 weights: Thin, UltraLight, Light, Regular, Medium, DemiBold, Bold, ExtraBold, Black, ExtraBlack, Heavy |
| `fanum/` | `IRANYekanXFaNum` | the same 11 weights with Persian digits |
| `noen/` | `IRANYekanXNoEn` | the same 11 weights without Latin glyphs |
| `variable/` | `IRANYekanXVF`, `IRANYekanXVFaNum` | the variable fonts (also in `../variable/`) |

`FontLicense.txt` (licence 136710) sits next to the fonts as the licence asks; `TERMS-fa.pdf` is
fontiran's terms of use as shipped. Proprietary: never published outside this private repository
and the hub's own renders. The six weights in `../static/` are the same files (the apps' set).
