# design/icons — آیکون‌های دیوان

**منبع واحد:** `icons.py`. اجرا: `python3 design/icons/icons.py` ← `svg/*.svg` و `icons.json` را از نو میسازد.
**هیچ آیکونی از Material، Lucide یا کتابخانه‌ی دیگر وارد UI نمیشود.** آیکون تازه اول به `icons.py` اضافه میشود و از دروازه‌ی تأیید مالک رد میشود.

## دستور ساخت
1. شبکه‌ی ۲۴، ناحیه‌ی زنده ۲ تا ۲۲. خط ۱٫۶، سر و اتصال گرد. اندازه‌ی پایه ۲۲ (`size.iconM`)، کوچک ۱۸ (`size.iconS`).
2. گوشه‌ها با برش ۴۵ درجه (برش دیوان)، نه گردی. گردی فقط برای دایره‌ی واقعی: سر انسان، مُهر، گوی.
3. **سر گرد = انسان (مالک)، سر هشت‌ضلعی = ایجنت.**
4. **«دل»:** هر آیکون میتواند یک شکل بسته‌ی `heart` داشته باشد که فقط در حالت فعال پر میشود. آیکون توپر جدا نداریم.
5. نقطه‌ها (نُکته) دایره‌ی ۲٫۵ پیکسلی‌اند.
6. فقط آیکون‌های جهت‌دار (`mirror: true`) در RTL آینه میشوند.

## قالب SVG
```
<svg viewBox="0 0 24 24" stroke="currentColor" stroke-width="1.6" ...>
  <path class="stroke" d="..."/>
  <path class="heart" d="..." fill="none" stroke="none"/>   ← در حالت فعال: fill = رنگ فعال
</svg>
```

## تحویل به کد (فاز ساخت، خودکار)
- **وب:** هر SVG یک کامپوننت React با `currentColor` و پراپ `active`.
- **اندروید:** همان مسیرها به `ImageVector` تبدیل میشوند.
- آیکون تنها (بی‌متن) برچسب دسترس‌پذیری فارسی دارد؛ آیکون کنار متن از صفحه‌خوان پنهان است.
