# design/ — طراحی CoinePro HQ (مال Claude سشن مشورت)

- **بوم طراحی (Artifact خصوصی مالک):** https://claude.ai/artifact/52T93fwA2WAkGrrVweQeUR
- **`canvas/`:** نسخه‌ی منبع همان بوم (فایل‌های `.dc.html`). فونت‌ها در خود بوم به‌صورت asset بارگذاری شده‌اند.
- **`fonts/`:** IRANYekanX Pro (متغیر و ایستا، دو واریانت ارقام) با `FontLicense.txt` و کد لایسنس مالک. **فقط برای محصولات مالک.**
- **`D0_BRIEF.md`:** بریف و دکترین طراحی «دیوان»، معماری اطلاعات، ناوبری و جریان‌ها.

| نسخه | محتوا | وضعیت |
|---|---|---|
| اسکیس v0 (۲۰۲۶-۱۰-۱۷) | پایه‌ی طراحی، مرکز فرمان اندروید و وب | منسوخ؛ فقط برای مقایسه |
| **D0 (۲۰۲۶-۱۰-۱۷)** | `D0_BRIEF.md` + تابلوی جهت بصری «دیوان» (شب و روز) | ❓ منتظر تأیید مالک (۸ سؤال در پایان بریف) |

**قاعده:** هیچ صفحه‌ای پیش از تأیید ماکاپش کدنویسی نمیشود. بعد از تأیید، توکن‌ها در `design/tokens/` به قالب Style Dictionary نوشته میشوند و هم وب و هم اندروید از همان ساخته میشوند.

## استاندارد مالک (۲۰۲۶-۱۰-۱۷)
✅ **همه‌ی طراحی، دیزاین و معماری پیاده‌سازی اپ و وب در سطح پرمیوم.** هیچ‌چیز ساده یا سرسری نیست.
✅ **مدل:** برای طراحی، دیزاین و معماری پیاده‌سازی اپ و وب، مالک سشن مشورت را روی **Fable 5.1** میبرد. هر جا کار به این سطح نیاز ندارد، Claude میگوید تا مالک به **Opus 5.5 (xhigh)** برگردد.

## روند پیشنهادی طراحی پرمیوم (❓ منتظر تأیید مالک)
پیشنهاد ۱ فقط یک اسکیس کارکردی بود. طراحی نهایی از صفر و با این روند ساخته میشود. **هر مرحله دروازه‌ی تأیید مالک دارد.**

| مرحله | خروجی |
|---|---|
| **D0 · بریف و دکترین** | شخصیت بصری، مرجع‌ها، اصول، معماری اطلاعات (نقشه‌ی صفحه‌های اپ و وب)، مدل ناوبری، فهرست جریان‌های کلیدی |
| **D1 · سیستم طراحی v1** | توکن‌ها (رنگ، تایپ، فاصله، ارتفاع، حرکت)، آیکون‌های اختصاصی، پالت نمودارها، کتابخانه‌ی کامپوننت‌ها با همه‌ی حالت‌ها (عادی، بارگذاری، خالی، خطا، آفلاین) |
| **D2 · کامپوننت‌های امضا** | گوی و گفت‌وگوی مشاور کل، «خلوت» و «در نبودت چه گذشت»، استریم زنده‌ی هلدینگ (مدار ۴۰ شرکت)، کارت کارمند، کارت پیشنهاد استخدام، کارت تصمیم، کارت خروجی با امتیاز ۱ تا ۱۰، نمودارهای خزانه‌ی توکن، پلنر، اتاق جلسه |
| **D3 · صفحه‌به‌صفحه** | همه‌ی صفحه‌های اصلی، موبایل و وب، با همه‌ی حالت‌ها، مشخصات حرکت، جزئیات RTL و دسترس‌پذیری |
| **D4 · پروتوتایپ قابل کلیک** | جریان‌های کلیدی: مالک ← مدیرعامل ← پیشنهاد استخدام ← تأیید؛ کارتابل تصمیم؛ گفت‌وگو با مشاور همراه با ارجاع؛ خلوت روشن و خاموش |
| **D5 · معماری پیاده‌سازی** | ساختار Next.js و اندروید، خط تولید توکن‌ها، کتابخانه‌ی کامپوننت، استریم زنده، تست بصری، بودجه‌ی کارایی |
