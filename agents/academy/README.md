# agents/academy — آکادمی هلدینگ (قرارداد §۱۸.۶)

> «فاین‌تیون» در هلدینگ یعنی لایه‌ی دانش خود ما (OPERATING_MODEL §۱.۳): منشور، مهارت، حافظه، playbook، نمونه‌ها و بازخوردها.
> آکادمی این لایه را **قابل سنجش** میکند: هر نقش برنامه‌ی آموزشی و **آزمون طلایی** دارد، و هیچ نسخه‌ی تازه‌ای از منشور، مهارت یا مدل
> بدون نمره‌ی برابر یا بهتر از خط پایه فعال نمیشود.

## پوشه‌ها
- `curricula.yaml`: برنامه‌ی آموزشی هر نقش (ماژول‌ها، مهارت‌ها، نمونه‌های خوب و بد).
- `evals/EV-NNN-<slug>.yaml`: مجموعه‌ی آزمون طلایی: هر مورد ورودی، معیار نمره و وزن دارد.

## چرخه
1. **آموزش مستقیم مالک** (ویس یا متن) ← مدیر عملیات هوش مصنوعی پیشنهاد دقیق میسازد (قاعده‌ی منشور، مهارت، حافظه یا playbook).
2. ناظر کل آن را بررسی میکند (تزریق، تناقض، اختیار اضافه).
3. آزمون طلایی نقش اجرا میشود؛ نمره ≥ خط پایه − ۱.
4. مالک تأیید میکند ← نسخه‌ی تازه فعال میشود و خط پایه بالا میرود.
5. **درس‌های هفتگی** از امتیازهای مالک، ستاره‌ها، یافته‌های ناظر، چالش‌ها و post-mortemها همین چرخه را طی میکنند.
