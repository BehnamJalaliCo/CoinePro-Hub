# agents/skills — کتابخانه‌ی مهارت (قرارداد §۱۸.۵)

> هر مهارت یک پوشه است: `SK-NNN-<slug>/SKILL.md` (frontmatter + دستورالعمل به انگلیسی برای مدل) و در صورت نیاز فایل‌های کمکی.
> این پوشه **بذر** کتابخانه است. مهارت‌های تازه را مالک در اپ میسازد (متن، ویس یا فایل)؛ ناظر کل بررسی میکند، آزمون آکادمی اجرا میشود،
> و با مُهر مالک فعال میشود. نسخه‌ی فعال هر مهارت در دیتابیس است؛ این فایل‌ها فقط نسخه‌ی ۱ را میسازند.

## frontmatter
| کلید | معنی |
|---|---|
| `ref` | `SK-NNN`، یکتا و ثابت |
| `name_fa`, `summary_fa` | چیزی که مالک میبیند |
| `roles` | نقش‌هایی که مهارت به آن‌ها اختصاص دارد (`ceo`، `manager`، …) یا `all` |
| `companies` | `all` یا فهرست کد شرکت‌ها |
| `version` | عدد صحیح؛ فقط بالا میرود |
| `eval` | مجموعه‌ی آزمون آکادمی که این مهارت را میسنجد (`EV-…`) |

## قواعد نوشتن
- مهارت **روش** است، نه اختیار: هیچ مهارتی ابزار تازه، کلاس اقدام بالاتر یا دسترسی تازه نمیدهد.
- کوتاه، دقیق، قابل آزمون: هر قاعده باید در یک آزمون طلایی قابل سنجش باشد.
- بدون رمز، داده‌ی مشتری یا نام آدم‌های بیرونی.
- موتور ایجنت مهارت‌های فعال نقش را **بعد از منشور** در system prompt میگذارد و در هر اجرا ثبت میکند کدام نسخه به کار رفت.
